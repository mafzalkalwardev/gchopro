# Contributing

- Read `GChoPro-PRD.md`, `PRD.md`, and `AGENTS.md`.
- Branch from `main`. Conventional commits.
- Milestone work lands on `m<N>-…` branches and opens a pull request. Do not push milestone commits straight to `main`.
- `pnpm lint`, `pnpm typecheck`, and `pnpm test` pass before a pull request.
- UI changes keep `DESIGN.md`, including reduced motion and the four widths (320, 768, 1024, 1440).
